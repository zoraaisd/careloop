WhatsApp Integration Setup

1

Create Twilio Account

Sign up at twilio.com and get your Account SID and Auth Token.

2

Enable WhatsApp Sandbox

Go to Messaging → Try it out → Send a WhatsApp message. Join sandbox by sending join [sandbox-word] from your WhatsApp.

3

Configure .env

WHATSAPP_PROVIDER=twilio
TWILIO_ACCOUNT_SID=ACxxxx
TWILIO_AUTH_TOKEN=your_token
TWILIO_WHATSAPP_NUMBER=whatsapp:+14155238886
4

Set Webhook URL

In Twilio console, set incoming webhook to:
http://your-server:3000/api/whatsapp/webhook

1

Meta Developer Account

2

Get Credentials

From WhatsApp → API Setup, copy your Phone Number ID and generate a temporary access token.

3

Configure .env

WHATSAPP_PROVIDER=meta
META_PHONE_ID=your_phone_number_id
META_ACCESS_TOKEN=your_access_token
META_VERIFY_TOKEN=health_verify_token
